# List registered handlers

List registered handlers

## Usage

``` r
handlers()
```

## Value

Character vector of handler names, sorted.

## Examples

``` r
handlers()
#>  [1] "anova_factorial"    "anova_oneway"       "chisq_gof"         
#>  [4] "chisq_independence" "cor_pearson"        "lm"                
#>  [7] "lm_moderation"      "lm_multiple"        "lm_simple"         
#> [10] "mediation_simple"   "t_independent"      "t_one_sample"      
#> [13] "t_paired"          
```
