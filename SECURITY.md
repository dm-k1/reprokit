# Security policy

reprokit runs locally in your R session. It handles no credentials,
makes no network connections and sends no data anywhere.

If you find a problem that you think should not be discussed in public
(for example, output that would reveal more about participants than the
disclosure check says), report it privately through GitHub: on the
repository page, open the **Security** tab and choose **Report a
vulnerability**
(<https://github.com/dm-k1/reprokit/security/advisories/new>). Please do
not open a public issue for it.

Only the latest version on the `main` branch is supported. Ordinary bugs
go to the [issue tracker](https://github.com/dm-k1/reprokit/issues).
